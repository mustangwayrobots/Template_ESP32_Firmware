## ✅ Setup checklist (delete this section when done)

You made this repo from **Template_ESP32_Firmware**. Do these once, in order.
The full walk-through is in **Instructor Guides → Create a New Repo**.

1. [ ] **Rename the sketch.** Open `Template_ESP32_Firmware.ino`, click the ✏️ pencil, and change the file name at the top to your repo name **exactly** (e.g. `Sumo_Bot.ino`). Commit.
2. [ ] Watch the **Actions** tab: the build should go green ✓ in a few minutes.
3. [ ] **Settings → Pages →** Deploy from a branch → **gh-pages** → **/ (root)** → Save.
4. [ ] Add the topic **`firmware`** (⚙️ gear next to **About**), plus `hidden` until it's ready for students.
5. [ ] Write the repo **Description** (⚙️ gear next to **About**): one sentence for students.
6. [ ] Test the Flash page in Chrome with a real board.
7. [ ] Replace the template code with your project, edit this README, and remove `hidden`.

**Arduino IDE:** clone or download this repo into your Arduino sketch folder. The folder name must match the `.ino` name. Board: **MakerGO ESP32 C3 SuperMini**.
**Libraries:** put every library this project uses in a `libraries/` folder in this repo. The GitHub build uses only those.
